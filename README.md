# Rust Projects

A collection of Rust learning projects and proof-of-concept implementations.

## Projects

- **test_args** - FFmpeg subtitle extraction tool
- **test_rest** - REST API client example with Tokio and Reqwest
- **notepad** - Windows service implementation example
- **proxy_poc** - TCP proxy server with encryption and REST integration
- **test_test** - REST API configuration and client testing

## Building

Each project can be built independently:

```bash
cd <project_name>
cargo build
cargo run
```

## Requirements

- Rust 2021 edition or later
- For test_args: FFmpeg and FFprobe in PATH
